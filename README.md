# Allow Mods In Campaign

<img src="preview.png" alt="Allow Mods In Campaign" width="400">

Use your mods and asset packs in the places the game turns them off: campaign levels, build challenges, and the custom campaign editor. Have fun!

**[Get it on the Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3350463035)**

## Description

Rules are made to be broken.

Normally the game switches every mod off in build challenges and custom campaigns, and asset packs won't load in the built-in campaign levels. This turns all of that back on. Modded stuff also skips scenario research, so you don't have to research your own custom deco before you can place it.

## How to Use

- Just turn it on. Next time you load one of those parks, your mods are there.
- Each part has its own checkbox in the mod settings if you only want some of it:
  - Allow mods in Build Challenges
  - Allow mods in the custom campaign editor and map
  - Load asset packs in campaign levels
  - Modded objects skip scenario research
- The first three apply the next time a park loads.

## Features

- Mods load in build challenges, the custom campaign editor, and the custom campaign map.
- Asset packs load in the built-in campaign levels.
- Modded objects are unlocked from the start in scenarios with research, and stay out of the research list. Only modded stuff, the game's own research is untouched.
- Campaign progress and achievements still work like normal.

## Compatibility

- Multiplayer: works, and not everyone needs it.
- Switching the mod off turns everything back to how the game normally does it.
